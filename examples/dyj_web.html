08按键 / 开关

动作在设备侧执行并持久化。按一下按键 / 拨开关，右侧「设备事件」应出现 BTN_CLICK / TOGGLE_SWITCH， 若绑定了录音动作还会跟一条 RECORD_STATUS（reason=button/switch）。 绑定表是否使用、默认绑什么由业务层决定；此分组只用于验证设备的配置通道。

09OTA

在线 OTA 需 STA 已连 + wifi_api_base_url 服务；下面两条不需要服务器。
主控：发 OTA → 设备重启进 bootloader（DFU_DYJ）→ 推 .zip 包（约 1–2 分钟，进度看日志）→ 自动重启进新固件，之后需重新扫描连接。 WiFi 本地：需电脑已连设备热点，上传 .bin 后 ESP32 3 秒自重启。
